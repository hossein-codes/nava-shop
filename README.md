# 🛍️ فروشگاه پوشاک «نوا» — نمونه‌کار با Next.js

یک فروشگاه آنلاین پوشاک کامل و راست‌چین (RTL) که با **Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4** ساخته شده است.

> این پروژه یک **نمونه‌کار (Portfolio)** است؛ داده‌ها و احراز هویت با `localStorage` مرورگر شبیه‌سازی شده‌اند تا بدون نیاز به بک‌اند اجرا شود.

## 🧠 نکات فنی (برای یادگیری)

- **RTL و فارسی**: از `dir="rtl"` و ویژگی‌های منطقی Tailwind (`ms-`, `me-`, `start-`, `end-`) استفاده شده تا با راست‌چین کامل درست کار کند.
- **فیلترها در URL**: فیلترهای صفحه محصولات در Query String ذخیره می‌شوند (`/products?category=women&size=M`) — لینک قابل اشتراک‌گذاری.
- **Context + localStorage**: سبد خرید، علاقه‌مندی‌ها، کاربران و سفارش‌ها در `localStorage` ذخیره می‌شوند؛ در نسخه‌ی واقعی باید این بخش‌ها را به یک API/دیتابیس وصل کنید.
- **Hydration**: داده‌های مرورگر فقط بعد از `mount` خوانده می‌شوند تا خطای Hydration پیش نیاید.

## 🎨 شخصی‌سازی سریع

- **تغییر محصولات**: فایل `lib/products.ts` را ویرایش کنید.
- **تغییر رنگ برند**: در `app/globals.css` مقادیر `@theme` را تغییر دهید.
- **تغییر لوگو و نام**: در `components/Header.tsx` و `components/Footer.tsx`.
- **تصاویر**: عکس‌های جدید را در `public/images/products/` قرار دهید و مسیر را در دیتا تغییر دهید.
